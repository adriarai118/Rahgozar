# رهگذر (Rahgozar)

فیلترشکن گرافیکی ویندوز با چند موتور، حالت TUN و پروکسی، و یادگیری خودکار.

## اجرا
1. فایل zip را باز کنید و `Rahgozar.exe` را اجرا کنید (WebView2 روی ویندوز ۱۰/۱۱ معمولاً نصب است).
2. در اولین اجرا موتورهای لازم (sing-box، Xray، Mihomo) خودکار از GitHub دانلود می‌شوند. اگر GitHub کند است، در «تنظیمات ← به‌روزرسانی» میرور وارد کنید یا از «موتورها ← نصب از فایل» فایل zip رسمی هر موتور را بدهید.
3. لینک‌ها را کپی کنید و در «سرورها» دکمه «از کلیپ‌بورد» را بزنید، یا اشتراک/فایل اضافه کنید.
4. برای حالت TUN برنامه را با دسترسی مدیر اجرا کنید (خود برنامه پیشنهاد می‌دهد).

## پروتکل‌ها و موتورها
| پروتکل | موتور |
|---|---|
| VLESS، VMess، Trojan، Reality، WS، gRPC، HTTPUpgrade، Shadowsocks (+plugin)، SOCKS5، HTTP(S)، SSH، AnyTLS | sing-box |
| Hysteria، Hysteria2 (پرش پورت)، TUIC | sing-box |
| WireGuard، OpenVPN (TCP/UDP، بدون درایور) | sing-box |
| XHTTP، mKCP، VLESS Encryption، هدر HTTP روی TCP | Xray-core |
| ShadowsocksR | Mihomo |
| PPTP، L2TP/IPsec، SSTP، IKEv2 | VPN داخلی ویندوز |
| TUN، DNS (DoH/DoT)، زنجیره پروکسی، مسیریابی | sing-box |

کنار هر سرور پرچم کشورش نمایش داده می‌شود: اول از روی نام سرور (پرچم ایموجی، نام فارسی یا انگلیسی کشور یا کد مثل DE)، و اگر نام چیزی نگفت از روی IP سرور با پایگاه‌داده داخلی (ip-location-db، CC0). پرچم‌ها از flag-icons (MIT).

ورودی‌ها: لینک‌های اشتراک‌گذاری، اشتراک base64، YAML کلش/میهومو، JSON سینگ‌باکس، فایل `.ovpn` و `.conf` وایرگارد.

## یادگیری
- **انتخاب هوشمند سرور:** نتیجه هر تست و هر بررسی سلامت به تفکیک شبکه (Wi-Fi/کابل) و بازه ساعت ذخیره می‌شود؛ هنگام اتصال، سرورهای برتر زنده تست و بهترین انتخاب می‌شود.
- **سلامت پروتکل‌ها:** اگر یک خانواده پروتکل (مثلاً vmess+ws+tls) روی شبکه فعلی مسدود شود، سرورهای آن پایین‌تر رتبه می‌گیرند.
- **تعویض خودکار:** سه شکست پشت سر هم یا کرش موتور ← انتقال به بهترین سرور بعدی.
- **مسیریابی هوشمند سایت‌ها:** سایت‌های جدید در پس‌زمینه مستقیم تست می‌شوند (DNS مسموم 10.10.34.x، ریست اتصال، 403 تحریم، کندی شدید) و فقط سایت‌های لازم از تونل می‌روند. فهرست‌ها بدون قطع اتصال روی sing-box اعمال می‌شوند.

## اکستنشن مرورگر (Chrome / Edge)
پوشه `extension` داخل zip برنامه (یا فایل `Rahgozar-extension.zip` در Releases) را در `chrome://extensions` با «Developer mode» و «Load unpacked» اضافه کنید، سپس «اتصال به رهگذر» را بزنید و داخل برنامه تأیید کنید.
- اتصال/قطع، انتخاب سرور، حالت TUN/پروکسی و نوع مسیریابی از داخل مرورگر
- تعیین مسیر سایت فعلی: خودکار / تونل / مستقیم / مسدود — بدون قطع اتصال اعمال می‌شود (کل دامنه یا فقط همان زیردامنه)
- کلیک راست روی صفحه یا لینک برای همین کارها
- نشان روی آیکون: T تونل، D مستقیم، ✕ مسدود
- «تست مستقیم/تونل» برای همین سایت، و تست سرعت همه سرورها
- «فقط این مرورگر از تونل» بدون نیاز به پروکسی ویندوز (با قطع اتصال خودکار برداشته می‌شود)
- میانبرها: `Alt+Shift+R` اتصال/قطع، `Alt+Shift+S` جابه‌جایی سایت بین تونل و مستقیم

آپدیت داخلی برنامه پوشه `extension` کنار برنامه را هم به‌روز می‌کند و اکستنشن خودش را دوباره بارگذاری می‌کند؛ به شرطی که اکستنشن از همین پوشه Load unpacked شده باشد.

ارتباط فقط روی `127.0.0.1:47123` است، درخواست‌های صفحات وب رد می‌شوند و هر مرورگر باید یک بار داخل برنامه تأیید شود.

## ساخت از سورس
```
go mod tidy
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -tags desktop,production -ldflags "-H windowsgui -s -w" -o Rahgozar.exe .
```
برای انتشار نسخه جدید، عدد داخل فایل `VERSION` را بالا ببرید و push کنید؛ workflow موجود در `.github/workflows/release.yml` فایل zip را می‌سازد و با تگ `v<نسخه>` در Releases منتشر می‌کند؛ آپدیت داخل برنامه از همین مخزن (تنظیمات ← مخزن آپدیت) خوانده می‌شود.

## ساختار
- `internal/parser` — خواندن لینک‌ها و فایل‌ها
- `internal/builder` — ساخت کانفیگ sing-box / Xray / Mihomo
- `internal/engine` — نصب، نسخه و آپدیت جداگانه هر موتور، اجرای پروسه‌ها
- `internal/core` — اتصال، TUN/پروکسی، تست، سلامت، failover، اشتراک‌ها، آپدیت برنامه
- `internal/smart` — یادگیری سرور/پروتکل/دامنه
- `internal/sys` — پروکسی ویندوز، دسترسی مدیر، RAS، شناسه شبکه
- `frontend/dist` — رابط کاربری
