# رهگذر (Rahgozar)

فیلترشکن گرافیکی برای **ویندوز** و **اندروید** با چند موتور، حالت TUN/VPN و پروکسی، و یادگیری خودکار. هر دو نسخه یک هسته (Go) و یک رابط کاربری مشترک دارند.

## دانلود
همه فایل‌ها در [Releases](../../releases/latest) هستند:

| فایل | برای |
|---|---|
| `Rahgozar-windows-amd64.zip` | ویندوز ۱۰/۱۱ (۶۴ بیتی) |
| `Rahgozar-android-arm64.apk` | اکثر گوشی‌های اندرویدی چند سال اخیر |
| `Rahgozar-android-armv7.apk` | گوشی‌های قدیمی ۳۲ بیتی |
| `Rahgozar-android.apk` | نسخه همگانی اندروید (هر دو معماری) |
| `Rahgozar-extension.zip` | اکستنشن Chrome / Edge |

## ویندوز
1. فایل zip را باز کنید و `Rahgozar.exe` را اجرا کنید (WebView2 روی ویندوز ۱۰/۱۱ معمولاً نصب است).
2. در اولین اجرا موتورهای لازم (sing-box، Xray، Mihomo) خودکار از GitHub دانلود می‌شوند. اگر GitHub کند است، در «تنظیمات ← به‌روزرسانی» میرور وارد کنید یا از «موتورها ← نصب از فایل» فایل zip رسمی هر موتور را بدهید.
3. لینک‌ها را کپی کنید و در «سرورها» دکمه «از کلیپ‌بورد» را بزنید، یا اشتراک/فایل اضافه کنید.
4. برای حالت TUN برنامه را با دسترسی مدیر اجرا کنید (خود برنامه پیشنهاد می‌دهد).

### System Tray
دکمه ضربدر برنامه را نمی‌بندد و به کنار ساعت ویندوز (System Tray) می‌برد (قابل خاموش کردن در تنظیمات). رنگ آیکون وضعیت را نشان می‌دهد (سبز متصل، زرد در حال اتصال، خاکستری قطع) و روی آن نام سرور و سرعت دیده می‌شود. کلیک: باز کردن پنجره. کلیک راست:
- اتصال / قطع اتصال، با وضعیت و سرعت لحظه‌ای
- انتخاب سرور (انتخاب هوشمند یا ۲۰ سرور برتر بر اساس یادگیری) — با انتخاب، اتصال برقرار می‌شود
- حالت TUN / پروکسی سیستم و نوع مسیریابی
- تست همه سرورها (نتیجه در اعلان)، وارد کردن از کلیپ‌بورد، کپی آدرس پروکسی محلی
- رفتن مستقیم به یادگیری، گزارش‌ها و تنظیمات
- خروج کامل

اگر «اجرا همراه ویندوز» روشن باشد، برنامه هنگام روشن شدن ویندوز مستقیم در Tray اجرا می‌شود.

## اندروید
1. APK را نصب کنید (اندروید ۷ به بالا؛ اجازه «نصب از منابع ناشناس» را بدهید) و در اولین اتصال اجازه VPN را تأیید کنید.
2. ظاهر و صفحه‌ها همان نسخه ویندوز است، با چیدمان موبایل (نوار پایین و پنجره‌های کشویی).
3. حالت‌ها: **VPN (کل گوشی)** یا **فقط پروکسی محلی**.
4. **تونل جداگانه برای هر برنامه** (مسیریابی ← برنامه‌ها): همه به‌جز برنامه‌های انتخابی، یا فقط برنامه‌های انتخابی.
5. اعلان با سرعت لحظه‌ای و دکمه قطع، کاشی Quick Settings برای وصل/قطع با یک لمس.
6. وارد کردن لینک با Share از تلگرام و برنامه‌های دیگر، باز کردن مستقیم لینک‌های `vless://`، `vmess://`، `ss://`، `hy2://` و …، یا از فایل.
7. شبکه محلی (`192.168.x.x`، `10.x.x.x` و …) از VPN عبور نمی‌کند، تا سرورهای روی گوشی (مثلاً یک صفحه وب محلی) از کامپیوترهای شبکه در دسترس بمانند.
8. آپدیت داخلی: APK جدید دانلود و نصب‌کننده اندروید باز می‌شود.

موتورها (sing-box، Xray و Mihomo) داخل خود برنامه‌اند و با آپدیت برنامه به‌روز می‌شوند؛ قوانین ایران جداگانه به‌روز می‌شود.
در اندروید پشتیبانی نمی‌شود: PPTP، L2TP، SSTP، IKEv2 و اکستنشن مرورگر.

## پروتکل‌ها و موتورها
| پروتکل | موتور | ویندوز | اندروید |
|---|---|:-:|:-:|
| VLESS، VMess، Trojan، Reality، WS، gRPC، HTTPUpgrade، Shadowsocks (+plugin)، SOCKS5، HTTP(S)، SSH، AnyTLS | sing-box | ✓ | ✓ |
| Hysteria، Hysteria2 (پرش پورت)، TUIC | sing-box | ✓ | ✓ |
| WireGuard + AmneziaWG (1.0 / 1.5 / 2.0 / 3) | Mihomo | ✓ | ✓ |
| OpenVPN (TCP/UDP، بدون درایور) | sing-box | ✓ | ✓ |
| XHTTP، mKCP، VLESS Encryption، هدر HTTP روی TCP | Xray-core | ✓ | ✓ |
| ShadowsocksR | Mihomo | ✓ | ✓ |
| PPTP، L2TP/IPsec، SSTP، IKEv2 | VPN داخلی ویندوز | ✓ | — |
| TUN، DNS (DoH/DoT)، زنجیره پروکسی، مسیریابی | sing-box | ✓ | ✓ |

**WireGuard در برابر DPI:** در ویندوز و اندروید سرورهای WireGuard به‌طور پیش‌فرض با Mihomo اجرا می‌شوند و قبل از هر handshake چند پکت تصادفی (Jc=3، 50 تا 1000 بایت) می‌فرستند؛ همان کاری که WireSock به‌طور پیش‌فرض می‌کند. سرور WireGuard معمولی این پکت‌ها را نادیده می‌گیرد، اما DPI را گمراه می‌کند. پارامترهای AmneziaWG (Jc، Jmin، Jmax، S1-S4، H1-H4 حتی به‌صورت بازه، I1-I5 و کلیدهای نسخه 3) و خط‌های `#@ws:` فایل‌های WireSock خوانده می‌شوند و در ویرایش سرور قابل تغییرند. `Jc = 0` یا انتخاب موتور sing-box یعنی WireGuard ساده.

**QR code:** دکمه «QR» در صفحه سرورها — در ویندوز اسکن کل صفحه (همه QRهای باز در تلگرام، مرورگر و …)، فایل تصویر، یا Ctrl+V / کشیدن تصویر؛ در اندروید دوربین (بدون نیاز به Google Play) یا گالری. کنار هر سرور هم دکمه نمایش QR هست تا کانفیگ را با گوشی از روی صفحه کامپیوتر اسکن کنید.

ورودی‌ها: لینک‌های اشتراک‌گذاری، اشتراک base64، YAML کلش/میهومو، JSON سینگ‌باکس، فایل `.ovpn` و `.conf` وایرگارد.

کنار هر سرور پرچم کشورش نمایش داده می‌شود: اول از روی نام سرور (پرچم ایموجی، نام فارسی یا انگلیسی کشور یا کد مثل DE)، و اگر نام چیزی نگفت از روی IP سرور با پایگاه‌داده داخلی (ip-location-db، CC0). پرچم‌ها از flag-icons (MIT).

## سرورها و اشتراک‌ها
- تست همه سرورها یا سرورهای انتخاب‌شده، مرتب‌سازی بر اساس کیفیت، ساخت زنجیره پروکسی از سرورهای انتخاب‌شده.
- تست سرورها همیشه **مستقیم** انجام می‌شود (نه از داخل VPN فعلی)، تا نتیجه نشان دهد سرور از اینترنت خود شما در دسترس است.
- **حذف قطع‌ها:** بعد از تست، دکمه «حذف قطع‌ها» سرورهایی را که جواب ندادند (در تب فعلی) با یک کلیک حذف می‌کند. سرور انتخاب‌شده و سرور متصل حذف نمی‌شوند؛ اگر همه قطع باشند اول هشدار می‌دهد.
- **حذف خودکار برای هر اشتراک:** با روشن کردن «حذف خودکار سرورهای قطع» در ویرایش اشتراک، بعد از هر به‌روزرسانی سرورها تست و قطع‌ها پاک می‌شوند (اگر همه قطع باشند چیزی حذف نمی‌شود).
- دریافت اشتراک از داخل تونل (اگر آدرس اشتراک فیلتر است)، نمایش حجم مصرفی و تاریخ انقضا.

## یادگیری
- **انتخاب هوشمند سرور:** نتیجه هر تست و هر بررسی سلامت به تفکیک شبکه (Wi-Fi/کابل/اپراتور موبایل) و بازه ساعت ذخیره می‌شود؛ هنگام اتصال، سرورهای برتر زنده تست و بهترین انتخاب می‌شود.
- **سلامت پروتکل‌ها:** اگر یک خانواده پروتکل (مثلاً vmess+ws+tls) روی شبکه فعلی مسدود شود، سرورهای آن پایین‌تر رتبه می‌گیرند.
- **تعویض خودکار:** سه شکست پشت سر هم یا کرش موتور ← انتقال به بهترین سرور بعدی.
- **مسیریابی هوشمند سایت‌ها:** سایت‌های جدید در پس‌زمینه مستقیم تست می‌شوند (DNS مسموم 10.10.34.x، ریست اتصال، 403 تحریم، کندی شدید) و فقط سایت‌های لازم از تونل می‌روند. فهرست‌ها بدون قطع اتصال روی sing-box اعمال می‌شوند.

## اکستنشن مرورگر (Chrome / Edge، فقط ویندوز)
پوشه `extension` داخل zip برنامه (یا فایل `Rahgozar-extension.zip`) را در `chrome://extensions` با «Developer mode» و «Load unpacked» اضافه کنید، سپس «اتصال به رهگذر» را بزنید و داخل برنامه تأیید کنید.
- اتصال/قطع، انتخاب سرور (با پرچم)، حالت TUN/پروکسی و نوع مسیریابی از داخل مرورگر
- تعیین مسیر سایت فعلی: خودکار / تونل / مستقیم / مسدود — بدون قطع اتصال اعمال می‌شود (کل دامنه یا فقط همان زیردامنه)
- کلیک راست روی صفحه یا لینک برای همین کارها
- نشان روی آیکون: T تونل، D مستقیم، ✕ مسدود
- «تست مستقیم/تونل» برای همین سایت، و تست سرعت همه سرورها
- «فقط این مرورگر از تونل» بدون نیاز به پروکسی ویندوز (با قطع اتصال خودکار برداشته می‌شود)
- میانبرها: `Alt+Shift+R` اتصال/قطع، `Alt+Shift+S` جابه‌جایی سایت بین تونل و مستقیم

اکستنشن داخل خود `Rahgozar.exe` است و هر بار اجرا در پوشه `extension` کنار برنامه به‌روز می‌شود؛ بنابراین آپدیت داخلی برنامه اکستنشن را هم به‌روز و دوباره بارگذاری می‌کند، به شرطی که از همین پوشه Load unpacked شده باشد.

ارتباط فقط روی `127.0.0.1:47123` است، درخواست‌های صفحات وب رد می‌شوند و هر مرورگر باید یک بار داخل برنامه تأیید شود.

## پشتیبان‌گیری و بازیابی
در «تنظیمات ← پشتیبان‌گیری و بازیابی»:
سرورهایی که sing-box نمی‌پذیرد (مثلاً کلید Reality یا short id خراب، رمزنگاری ناشناخته Shadowsocks) هنگام وارد کردن با دلیل رد می‌شوند و در تست‌ها کنار گذاشته می‌شوند تا یک سرور خراب تست بقیه را از کار نیندازد.

- **ساخت فایل پشتیبان** (`.rgbak`): سرورها، اشتراک‌ها و به انتخاب شما تنظیمات و داده یادگیری؛ با رمز اختیاری (AES-256-GCM). فایل ویندوز روی اندروید هم بازیابی می‌شود و برعکس.
- **بازیابی**: چیزی پاک نمی‌شود؛ سرورها و اشتراک‌های تازه اضافه می‌شوند (تکراری‌ها رد می‌شوند، زنجیره‌ها و ارتباط سرور با اشتراک حفظ می‌شود). در بازیابی تنظیمات، موارد مخصوص همان دستگاه (حالت اتصال، اکستنشن، Tray، تونل برنامه‌ها) دست نمی‌خورند و فهرست سایت‌ها با فهرست فعلی یکی می‌شود.
- **از برنامه‌های دیگر**: پشتیبان Exclave (فایل `.json`؛ اشتراک‌ها، سرورهای دستی و به انتخاب شما سرورهای ذخیره‌شده اشتراک‌ها — VLESS/Reality/XHTTP، VMess، Trojan، Shadowsocks، SSR، WireGuard، Hysteria2، TUIC، SOCKS، HTTP، SSH، AnyTLS)، پشتیبان کامل WG Tunnel (`.zip`، `.sqlite3` یا `.aes` با رمز)، خروجی zip تونل‌های WG Tunnel، WireGuard و WireSock، و هر zip شامل فایل‌های `.conf` / `.ovpn` / Clash / sing-box. این فایل‌ها از دکمه «فایل» در صفحه سرورها هم وارد می‌شوند.

## به‌روزرسانی
- **برنامه:** از داخل «تنظیمات ← به‌روزرسانی»؛ ویندوز فایل zip و اندروید فایل APK را از Releases همین مخزن می‌گیرد.
- **موتورها (ویندوز):** هر موتور جداگانه با امکان بازگشت به نسخه قبل؛ نصب از فایل برای وقتی GitHub در دسترس نیست.
- **قوانین ایران:** جداگانه در هر دو نسخه.

## ساخت از سورس
ویندوز:
```
go mod tidy
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -tags desktop,production -ldflags "-H windowsgui -s -w" -o Rahgozar.exe .
```

اندروید (نیاز به Go، JDK 17، Android SDK/NDK و gomobile):
```
cd mobile
go mod tidy && go get golang.org/x/mobile/bind
gomobile init
gomobile bind -target android/arm64,android/arm -androidapi 24 \
  -tags "with_gvisor,with_quic,with_wireguard,with_utls,with_clash_api,with_openvpn,badlinkname,tfogo_checklinkname0" \
  -ldflags "-checklinkname=0" -o ../android/app/libs/gocore.aar ./gocore
cd .. && cp -r frontend/dist/. android/app/src/main/assets/web/
gradle -p android assembleRelease
```

### انتشار
عدد داخل فایل `VERSION` را بالا ببرید و push کنید؛ workflow موجود در `.github/workflows/release.yml` نسخه ویندوز، اکستنشن و APKها را می‌سازد و با تگ `v<نسخه>` در Releases منتشر می‌کند.

برای امضای ثابت APK (لازم برای آپدیت بدون حذف برنامه) این دو Secret در تنظیمات مخزن لازم است: `ANDROID_KEYSTORE_B64` (فایل keystore به base64) و `ANDROID_KEYSTORE_PASSWORD`. بدون آن‌ها APK با کلید موقت امضا می‌شود.

## ساختار
- `internal/parser` — خواندن لینک‌ها و فایل‌ها
- `internal/builder` — ساخت کانفیگ sing-box / Xray / Mihomo (شامل تنظیمات مخصوص اندروید)
- `internal/engine` — نصب، نسخه و آپدیت جداگانه هر موتور، اجرای پروسه‌ها
- `internal/core` — اتصال، TUN/پروکسی، تست، سلامت، failover، اشتراک‌ها، آپدیت برنامه
- `internal/smart` — یادگیری سرور/پروتکل/دامنه
- `internal/geo` — تشخیص کشور سرور
- `internal/desk` — منطق برنامه و API مشترک ویندوز و اندروید، API اکستنشن
- `internal/sys` — پروکسی ویندوز، دسترسی مدیر، RAS، شناسه شبکه
- `main.go`، `platform_wails.go` — پوسته ویندوز (Wails)
- `mobile/gocore` — هسته اندروید (gomobile): VPN با libbox، Xray داخلی، پل رابط کاربری
- `android/` — برنامه اندروید (Kotlin): WebView، VpnService، اعلان، کاشی، وارد کردن لینک
- `frontend/dist` — رابط کاربری مشترک
- `extension/` — اکستنشن Chrome/Edge
